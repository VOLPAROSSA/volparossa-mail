Project VOLPAROSSA · Thunderbird integration

Work with the cooperative network on text you are authorized to make public.

No email, address, account, draft or attachment is read automatically. Ordinary mail continues to use Thunderbird's existing accounts.

This is a native Tools integration, not an upstream Thunderbird Assist provider. Private correspondence is not supported by the public cooperative service.

Configure mail.volparossa.compute.public_socket with the same-user core public-task Unix socket. There is no automatic cloud or local-only substitute.
