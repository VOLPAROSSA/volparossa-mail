Project VOLPAROSSA · Mail integration

Your mail host, explicitly connected

Connect a Stalwart user account, view its mailboxes and import a message file you select.

Development connector — not a decentralised mail gateway. Prefer a Stalwart server on your own device. A remote origin connects to that server's operator; use it only when you deliberately trust that operator with your mail, never a randomly selected peer. The selected server can read imported messages unless their contents are already end-to-end encrypted. Stalwart encryption at rest does not hide plaintext from an SMTP receiver. This screen does not send mail, configure a server, forward messages through peers, or publish email to the cooperative AI. Existing Thunderbird accounts are untouched.

1. Connect your account

An HTTPS origin only, including an optional port. HTTP is accepted only on the literal loopback addresses 127.0.0.1 and [::1]. No redirects or alternate server origins.

The password stays in this tab's memory only until disconnect or tab close. No account credentials are saved by this extension. Thunderbird may remember the separate host-access permission.

2. Choose an account

Nothing is read from other Thunderbird accounts. Mailbox names and message counts appear only after this confirmation; message bodies are not retrieved.

    3. Import a selected message

    Maximum 8 MiB, or the server's smaller upload limit.

    No automatic retries. If completion is uncertain, inspect the mailbox before importing again to avoid duplicates. A metadata readback is not a raw-message integrity check.
